# 🏰 אומות וממלכות — משחק אסטרטגיית זמן־אמת בדפדפן

משחק RTS בסגנון Age of Empires, רץ בדפדפן, עם **ממשק עברי מלא (RTL)**.
מתחילים מיישוב קטן, אוספים משאבים, בונים, מאמנים צבא, גדלים בארבעה שלבי צמיחה ומתמודדים מול אומות שנשלטות על ידי המחשב.

TypeScript · Vite · Canvas 2D · Vitest — בלי תלויות ריצה חיצוניות.

---

## הרצה מהירה

```bash
npm install
npm run dev       # שרת פיתוח — פותחים את הכתובת שמודפסת (בדרך כלל http://localhost:5173)
```

פקודות נוספות:

```bash
npm test          # כל בדיקות היחידה (Vitest)
npm run test:watch# בדיקות במצב צפייה
npm run typecheck # בדיקת טיפוסים בלבד
npm run build     # בנייה לייצור אל dist/ (כולל בדיקת טיפוסים)
npm run preview   # תצוגה מקדימה של הבנייה
```

הבנייה יוצרת קבצים סטטיים בלבד (`dist/`), אפשר להעלות לכל אירוח סטטי.

### לשחק מהטלפון באותה רשת

```bash
npm run dev -- --host
```

הפקודה מדפיסה גם כתובת `Network:` — פותחים אותה בדפדפן בטלפון.
המשחק תומך במגע: נגיעה = בחירה, נגיעה ארוכה = פקודה, שתי אצבעות = זום והזזה.

### פרסום אונליין (GitHub Pages)

הריפוזיטורי כולל שני תהליכי GitHub Actions:

* `.github/workflows/ci.yml` — רץ על כל דחיפה ועל כל PR: התקנה, בדיקת טיפוסים, 167 הבדיקות ובנייה.
* `.github/workflows/deploy.yml` — בונה ומפרסם את המשחק ל-GitHub Pages.

**הפעלה חד־פעמית:** בהגדרות הריפוזיטורי → *Pages* → *Source* → בוחרים **GitHub Actions**.
מאותו רגע כל דחיפה ל-`main` מפרסמת את הגרסה העדכנית, והמשחק זמין בכתובת
`https://<שם-המשתמש>.github.io/<שם-הריפו>/` — נפתח בכל דפדפן, גם בטלפון, בלי להתקין דבר.
אפשר גם לפרסם ידנית מכל ענף דרך *Actions* → *פרסום ל-GitHub Pages* → *Run workflow*.

הבנייה משתמשת ב-`base: './'`, כך שהמשחק עובד גם מתת־נתיב (כמו `/New-game/`) בלי הגדרות נוספות.

## מערכות הליבה

### מפה וערפל מלחמה
מפה של 128×128 אריחים (ניתן לבחור 96 עד 160) שנוצרת פרוצדורלית מזרע:
גבעות, עשב, חול, מים רדודים ועמוקים, יערות, מכרות אבן וזהב, שיחי פירות ודגים.
לכל שחקן שתי שכבות ערפל — *נחקר* (זוכר מה ראינו) ו*נראה עכשיו*.
בעלי ברית חולקים ראייה. המנוע מוודא שלכל נקודת פתיחה יש עץ, פירות, זהב ואבן בקרבת מקום.

**נקודות הפתיחה תמיד מחוברות ביניהן:** המנוע מחשב את רכיבי הקשירות של המפה
ובוחר את כל נקודות הפתיחה מתוך היבשת הגדולה ביותר, בסריקת גריד קבועה עם פיזור
max-min. כך תמיד קיים מסלול יבשתי בין כל שני שחקנים — גם במפות עם הרבה מים.
בדיקה אוטומטית מאמתת את זה על כל תבנית מפה, בכמה זרעים ובכמה מספרי שחקנים.

### סוגי מפות

השחקן בוחר תבנית מפה במסך הפתיחה. כל תבנית מוגדרת ב-`src/data/maps.json`
(כמות מים, צפיפות יערות, גובה ההרים, הטיית לחות, צפיפות מכרות ופירות, ותכונה
גאוגרפית מיוחדת), כך שהוספת מפה חדשה היא רשומת JSON בלבד.

| מפה | אופי |
| --- | --- |
| 🌳 ארץ ירוקה | מאוזנת לכל סגנון משחק — מומלצת למתחילים |
| 🌾 מישורים פתוחים | כמעט בלי מכשולים; תנועה מהירה ומעט עץ |
| 🌲 יער עד | עץ בשפע, שטחי בנייה מצומצמים ומעברים צרים |
| 🏜️ מדבר | זהב ואבן בשפע, כמעט בלי עץ, אוכל מרוכז בנאות מדבר |
| ⛰️ רמות וגבעות | רכסים ועמקים צרים; תנועה איטית אך הגנה טובה |
| 💧 ארץ האגמים | אגמים גדולים שמחוברים במעברי יבשה צרים |
| 🌊 שני גדות הנהר | נהר חוצה מפה עם מעברות רדודות כנקודות מפתח |
| 🧊 פיורדים צפוניים | חופים משוננים, מפרצים עמוקים ויערות אורנים |

בנוסף יש אפשרות "מפה אקראית", והמצב "משחק מהיר" בוחר אומה ומפה באקראי.

### ניווט
A* עם 8 כיוונים, משקולות קרקע (יער איטי, גבעה איטית), מניעת חיתוך פינות והחלקת מסלול בקו ראייה.
בנוסף: הימנעות מקומית בין יחידות (כוח הדיפה), החלקה לאורך מכשולים, שחרור אוטומטי מתקיעות
ותקציב חישובי מסלול לפריים כדי לשמור על קצב פריימים יציב.
פורמציות: ריבוע, שורה, טריז ופיזור — מסובבות לכיוון התנועה.

### כלכלה
ארבעה משאבים: **אוכל, עץ, אבן, זהב**. פועלים אוספים עד מגבלת נשיאה וחוזרים לנקודת פריקה
(מרכז היישוב, בית גרנות, מחנה עצים, מחנה כרייה). כשהמשאב נגמר הם עוברים אוטומטית לאריח סמוך מאותו סוג.
תקרת האוכלוסייה עולה עם בתים, מבנים מיוחדים, שלבי צמיחה וטכנולוגיות.

### בנייה ואימון
תורי אימון (עד 10 יחידות), נקודת כינוס (גם על משאב — אז היחידה יוצאת לאסוף), תיקון מבנים,
ביטול עם החזר משאבים, ומגבלות כמות למבנים מיוחדים.

### קרב
לכל יחידה: תקיפה, סוג תקיפה (מגע / חודר / מצור / נ״מ), שריון ושריון חודר, טווח וקצב.
מעליהם מערכת יחסי חוזק:

| התוקף | חזק מול | חלש מול |
| --- | --- | --- |
| חי״ר | פרשים, מצור | יחידות אוויריות |
| לוחמי טווח | חי״ר | פרשים |
| פרשים / שריון | לוחמי טווח, מצור, פועלים | חי״ר |
| מצור | מבנים | פרשים |
| אווירי | מצור, פועלים | נ״מ והגנה אווירית |

בנוסף לכל יחידה בונוסים משלה (נושא חנית נגד פרשים, נ״מ נגד אוויר, איל ניגוח נגד מבנים).

### מערכת הצמיחה (במקום עידנים)
כל אומה מתחילה ביישוב קטן וגדלה בארבעה שלבים. המעבר דורש **משאבים + אוכלוסייה + מבנים** ולוקח זמן.
כל שלב משנה את **המראה והשם של מרכז היישוב**, פותח מבנים, יחידות וטכנולוגיות, מוסיף לתקרת האוכלוסייה
ומגדיל את **רדיוס השליטה** על המפה (מצויר כמעגל מקווקו).

### ישראל — בחירות

**לפני המשחק בוחרים נקודת פתיחה:**

* **קיבוץ 🌻** — כלכלה שיתופית: +15% איסוף, מחקר מהיר ב-20%, חדר אוכל ומפעל,
  ובסוף המסלול **עיר תעשייה והייטק** (בונוסים למחקר, שריון וטכנולוגיה).
* **מושב 🚜** — משקים פרטיים: בתים וחוות זולים ב-15%, +3 אוכלוסייה לכל בית, +30% זהב ממסחר,
  ובסוף המסלול **עיר מסחר וחקלאות**.

**בשלב 3 (עיירה) בוחרים זרוע צבאית:**

| זרוע | יחידות |
| --- | --- |
| 🎖️ חי״ר | לוחם גולני, חייל חי״ר, רובאי |
| 🚐 שריון | נגמ״ש נמר, טנק מרכבה |
| 🎯 צלפים וכוחות מיוחדים | צלף, לוחם סיירת |
| 📡 הגנה אווירית | מל״ט, סוללת יירוט ניידת, וכיפת ברזל להגנת היישוב |

**מבנים ייחודיים:** מגדל מים 💧, חדר אוכל 🍽️, בית ספר 🏫, בסיס צבאי 🏕️,
כיפת ברזל 📡, בית חולים 🏥 ובורסה 💹.

### ויקינגים — בחירות

בהשראת עמי הצפון: חקלאים־לוחמים, ספנים ואומני עץ ומתכת.
**יתרונות:** בונדי (חיל רגלים) זול ומהיר במיוחד לאימון, +2 טווח ראייה לכל היחידות,
ונמלי סחר שמכניסים זהב ואוכל בהתמדה.

**בשלב עיירת הנמל בוחרים את דרך הצפון:**

* **דרך הסוחרים ⚓** — מסעות מסחר ארוכים: +35% זהב ממסחר, +15% איסוף ומחקר מהיר.
* **דרך הלוחמים 🛡️** — חומת מגנים והוסקרלים: +15% תקיפה לחי״ר, +1 שריון ו-+10% חיים.

**מבנים ייחודיים:** לונגהאוס 🛖, אולם המשתה 🍺, נמל סחר ⚓ ובית מלאכה ⚒️.

## הוספת אומה חדשה

המערכת מונעת נתונים — אין צורך לגעת בקוד המנוע:

1. מוסיפים יחידות ל-`src/data/units.json` (מזהה, שם, אמוג׳י, סוג, עלות, נתוני קרב).
2. מוסיפים מבנים ל-`src/data/buildings.json`. מבנה שמאמן יחידות מציין אותן ב-`trains`.
3. מוסיפים רשומת אומה ל-`src/data/nations.json` עם ארבעה שלבי צמיחה,
   רשימות `unlocks` לכל שלב, ואופציונלית `branches` (בחירות של השחקן).
4. `npm test` — בדיקת `tests/data.test.ts` תאמת שכל ההפניות תקינות ושיש נתיב יחידות מלא.

ה-AI מסווג מבנים לפי תפקיד ישירות מהנתונים (בית / נקודת פריקה / מבנה צבא / הגנה / מחקר / כלכלה),
ולכן הוא יודע לשחק עם אומה חדשה בלי שינוי קוד.

## יריב המחשב

ארבע רמות קושי — **קל · רגיל · קשה · אכזרי** — שנבדלות בקצב החשיבה, יעד הפועלים, מספר מבני הצבא,
גודל גלי ההתקפה, תדירותם ומידת האגרסיביות. ה-AI:

* מאזן פועלים בין ארבעת המשאבים לפי יחס מטרה ולפי מחסור בפועל;
* בונה לפי סדר עדיפויות (בתים כשהאוכלוסייה נחנקת → נקודות פריקה → דרישות השלב הבא → צבא → כלכלה → מחקר → הגנה);
* בוחר יחידות לאימון לפי הצבא שהוא רואה אצל היריב (מנצל בונוסים);
* מתקדם בשלבי הצמיחה ובוחר ענפים בעצמו;
* מגיב להתקפות על הבסיס ושולח גלי התקפה לעבר המבנה הקרוב של היריב.

## אמנות ואודיו

המשחק מצויר **באיזומטריה 2:1** — אותה זווית מבט שמוכרת ממשחקי אסטרטגיה קלאסיים.
כל הגרפיקה נוצרת פרוצדורלית ב-Canvas, בלי קבצי אמנות חיצוניים:

* **אנשים מונפשים** — כל דמות נבנית מגוף, ראש, רגליים, זרועות וכלי עבודה, עם מחזור
  הליכה ועם אנימציית עבודה שונה לכל פעולה: כריתת עצים, כרייה, בנייה, חקלאות וקרב.
* **מבנים תלת-ממדיים** — מורכבים מתיבות, גגות רעפים משופעים, גגות פירמידה, עמודים
  ודגלים. לכל אומה לוח צבעים משלה, ולכל תפקיד מבנה "ארכיטיפ" ציור משלו (בית, אסם,
  קסרקטין, מגדל, מקדש, מצודה, מפעל, מכ"ם, נמל…). מבנה חדש ב-JSON מקבל ארכיטיפ
  אוטומטית לפי תפקידו.
* **כלי רכב** — טנק, נגמ"ש, ג'יפ, סוללת יירוט, מל"ט מרחף, מכונות מצור ומרכבות.
* **טבע** — עצי מחט ועצי צל עם נוף מרובד, מכרות אבן וזהב, שיחי פירות, שדות חרושים
  ומים מרצדים.
* **תבליט** — גבעות מוגבהות עם דפנות מוצללות, וצל לכל יחידה ומבנה.

**ביצועים.** שלוש אופטימיזציות שנמדדו מול פרופיילר בדפדפן אמיתי:

1. **שכבת קרקע מטמונה בנתחים** — הקרקע והעצים נצרבים לקנבסים של 12x12 אריחים
   ומועתקים 1:1 (הזום מקובע לצעדים שלמים כדי להימנע מדגימה מחדש).
2. **מטמון ספרייטים לדמויות** — כל שילוב של יחידה/פעולה/פריים/כיוון/צבע מצויר פעם
   אחת ומועתק. ציור דמות עולה 12 פעולות מסלול; העתקה עולה אחת.
3. **ערפל כטקסטורה אחת** — במקום מעוין לכל אריח, נבנית תמונה ברזולוציה כפולה עם
   ריכוך דו-לינארי (רק כשהערפל משתנה) ומצוירת בהעתקה אחת דרך ההקרנה האיזומטרית.

יחד: **מ-25 ל-50 פריימים לשנייה** עם 130 יחידות על המסך, בדפדפן ללא האצת חומרה.

האודיו נוצר בזמן אמת ב-WebAudio (בלי קבצים): בחירה, פקודה, בנייה, אימון, מכה, מוות,
מעבר שלב, התראת התקפה, ניצחון והפסד, ועוד מוזיקת רקע רגועה. להחלפה בקבצים אמיתיים
ממלאים את `SOUND_FILES`.

## מסך הפתיחה

מסך הפתיחה מציג **סצנת יישוב איזומטרית חיה** — בתים, חווה, מגדל, עצים ואנשים
שמסתובבים ועובדים — שמצוירת באותן פונקציות ציור כמו המשחק עצמו. כך מה שרואים
בתפריט הוא בדיוק מה שמקבלים במשחק. האנימציה נעצרת כשהתפריט נסגר.

## שמירה וטעינה

שמירה ל-`localStorage` כוללת את המפה (קרקע + מצב המשאבים שנותרו), את כל הישויות,
את מצב השחקנים (משאבים, שלב, מעבר שלב פעיל, פתיחות, טכנולוגיות) ואת שכבת הערפל הנחקר (בדחיסת RLE).
הגרסה נשמרת בקובץ; שמירה מגרסה ישנה נדחית בהודעה ברורה במקום להיטען שבורה.

## החלטות עיצוב שהתקבלו בדרך

נקודות שלא פורטו בבקשה והוכרעו כאן:

1. **ממשק ב-DOM מעל הקנבס** ולא טקסט מצויר בקנבס — כדי לקבל RTL אמיתי, שבירת שורות נכונה בעברית,
   נגישות וגדלי מגע נוחים במובייל. רק שדה המשחק והמיני-מפה מצוירים בקנבס.
2. **Canvas 2D ולא PixiJS** — אין תלות ריצה חיצונית, הבנייה קטנה (~47KB gzip), וזה מספיק לעומס הנוכחי.
   שכבת הקרקע נצרבת פעם אחת לקנבס נפרד כדי לא לצייר 16,384 אריחים בכל פריים.
3. **מרכז אריח ב-(x+0.5, y+0.5)** והמרה לאריח ב-`Math.floor` בכל המנוע (`toTile`).
4. **חוות מייצרות אוכל באופן פסיבי** ולא כאריח שנחרש ומתרוקן — פשוט יותר, שומר על כלכלה זורמת בשלבים המאוחרים.
5. **תיקון מבנים חינם** (ללא עלות משאבים) ובקצב של 3.5% מנקודות החיים לשנייה — כדי לא להעניש בנייה הגנתית.
6. **אין לחימה ימית ואין ספינות** — המים משמשים כמכשול טבעי, כמקור דגים ולעיצוב המפה בלבד.
7. **בניית מבנה גובה את מלוא המחיר מראש**; ביטול מחזיר את החלק שטרם נבנה.
8. **יחידות אוויריות מתעלמות מקרקע** (עפות מעל מכשולים) ונפגעות במיוחד מנ״מ ומהגנה אווירית.
9. **מעבר שלב הוא השקעה**: המשאבים נגבים בהתחלה, יש טיימר, וביטול מחזיר הכול.
10. **בחירת ענף בזמן משחק משהה את המשחק** (שלב 3 אצל ישראל ויפן והערבים) כדי שהבחירה תהיה מודעת.
11. **תקרת אוכלוסייה מוחלטת: 200** — שומרת על ביצועים יציבים גם במשחק ארוך.
12. **ה-AI לא מרמה במשאבים**; ההבדל בין הרמות הוא בקצב ההחלטות, ביעדים ובאגרסיביות בלבד.
13. **המשחק נשמר בסלוט אחד ("auto") דרך שמירה מהירה**, ורשימת השמירות במסך הפתיחה תומכת בכמה סלוטים
    למי שירצה להוסיף בעתיד.
14. **זום פתיחה מותאם למסך** — במובייל רואים בערך 20 אריחים לרוחב, כדי שהמשחק יהיה שחיק במסך קטן.
15. **נקודות פתיחה נבחרות מהיבשת הגדולה ביותר בלבד**, בסריקת גריד קבועה (לא בהגרלה) ובפיזור max-min.
    הגרלה נטתה להצמיד שני שחקנים זה לזה במפות עם יבשת בצורה לא סדירה.
16. **משאבי הפתיחה נשתלים בשני מעברים** — קודם מנקים את השטח סביב *כל* נקודות הפתיחה ורק אחר כך שותלים,
    ושום משאב לא נשתל במרחק 4 אריחים או פחות מנקודת פתיחה כלשהי. אחרת שתילה של שחקן אחד חסמה את שטח
    הבנייה של שחקן אחר.
17. **צפיפות "יער עד" כוילה לפי מדידה** ולא לפי תחושה: בצפיפות מלאה נשארו 19 שטחי בנייה 4×4 בכל המפה
    ואף אומה לא הצליחה להתפתח. הערך הנוכחי (0.75) משאיר ~335 שטחים ועדיין פי כמה עצים ממפת המישורים.
18. **הגרפיקה איזומטרית ומצוירת בקוד, לא בספרייטים.** זה לא משיג איכות של משחק עם
    אולפן אמנות, אבל נותן מראה תלת-ממדי עקבי, משקל הורדה זעיר (~63KB gzip לכל המשחק)
    ויכולת להוסיף אומות ומבנים בלי לצייר נכס חדש.
19. **כיוון היחידות מצויר בשני כיוונים בלבד** (ימין/שמאל) ולא בשמונה. זה מה שמאפשר
    את מטמון הספרייטים, וההבדל כמעט לא מורגש בזווית הזו.
20. **הזום מקובע לצעדים של 2 פיקסלים.** בלי זה שכבת הקרקע המטמונה נדגמת מחדש בכל
    פריים, וזה לבדו עלה כ-14ms לפריים.
21. **הזרוע הישראלית מבוססת על ציוד מוכר של צה"ל** (טנק מרכבה, נגמ"ש נמר, כיפת ברזל).
    השמות מתייחסים לציוד בלבד, בלי ייצוג של סכסוכים, מבצעים או יריבים אמיתיים —
    בדיוק כמו הסמוראי של יפן או הלגיונר של רומא.
22. **הלונגהאוס הוא מבנה מגורים בלבד ואינו מאמן יחידות.** כשהוא גם אכלס וגם אימן, ה-AI סיווג אותו
    כמבנה צבא, בנה ממנו הרבה, הציף יחידות זולות וריקן את מלאי האוכל עד שלא הצליח לעבור שלב.
    אימון הבונדי נעשה בקסרקטין.

## גישה לתוכן

הסגנון קליל ולא־ריאליסטי, ובנוי סביב בנייה, כלכלה, צמיחה ואסטרטגיה.
כל האומות מוצגות בכבוד ובעומק שווה — לכל אחת מסלול צמיחה מלא בן ארבעה שלבים, יתרונות ייחודיים,
מבנים משלה ותיאור שמדגיש תרבות, מדע, מסחר או בנייה. היריבים במשחק הם אומות שנשלטות על ידי המחשב,
ואין במשחק ייצוג של סכסוכים או של קבוצות אמיתיות בהווה.
