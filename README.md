# 🏰 אומות וממלכות — משחק אסטרטגיית זמן־אמת בדפדפן

משחק RTS בסגנון Age of Empires, רץ בדפדפן, עם **ממשק עברי מלא (RTL)**.
מתחילים מיישוב קטן, אוספים משאבים, בונים, מאמנים צבא, גדלים בארבעה שלבי צמיחה ומתמודדים מול אומות שנשלטות על ידי המחשב.

TypeScript · Vite · Canvas 2D · Vitest — בלי תלויות ריצה חיצוניות.

---

## הרצה מהירה

```bash
npm install
npm run dev       # שרת פיתוח — פותחים את הכתובת שמודפסת (בדרך כלל http://localhost:5173)
```

פקודות נוספות:

```bash
npm test          # כל בדיקות היחידה (Vitest)
npm run test:watch# בדיקות במצב צפייה
npm run typecheck # בדיקת טיפוסים בלבד
npm run build     # בנייה לייצור אל dist/ (כולל בדיקת טיפוסים)
npm run preview   # תצוגה מקדימה של הבנייה
```

הבנייה יוצרת קבצים סטטיים בלבד (`dist/`), אפשר להעלות לכל אירוח סטטי.

## מערכות הליבה

### מפה וערפל מלחמה
מפה של 128×128 אריחים (ניתן לבחור 96 עד 160) שנוצרת פרוצדורלית מזרע:
גבעות, עשב, חול, מים רדודים ועמוקים, יערות, מכרות אבן וזהב, שיחי פירות ודגים.
לכל שחקן שתי שכבות ערפל — *נחקר* (זוכר מה ראינו) ו*נראה עכשיו*.
בעלי ברית חולקים ראייה. המנוע מוודא שלכל נקודת פתיחה יש עץ, פירות, זהב ואבן בקרבת מקום.

### ניווט
A* עם 8 כיוונים, משקולות קרקע (יער איטי, גבעה איטית), מניעת חיתוך פינות והחלקת מסלול בקו ראייה.
בנוסף: הימנעות מקומית בין יחידות (כוח הדיפה), החלקה לאורך מכשולים, שחרור אוטומטי מתקיעות
ותקציב חישובי מסלול לפריים כדי לשמור על קצב פריימים יציב.
פורמציות: ריבוע, שורה, טריז ופיזור — מסובבות לכיוון התנועה.

### כלכלה
ארבעה משאבים: **אוכל, עץ, אבן, זהב**. פועלים אוספים עד מגבלת נשיאה וחוזרים לנקודת פריקה
(מרכז היישוב, בית גרנות, מחנה עצים, מחנה כרייה). כשהמשאב נגמר הם עוברים אוטומטית לאריח סמוך מאותו סוג.
תקרת האוכלוסייה עולה עם בתים, מבנים מיוחדים, שלבי צמיחה וטכנולוגיות.

### בנייה ואימון
תורי אימון (עד 10 יחידות), נקודת כינוס (גם על משאב — אז היחידה יוצאת לאסוף), תיקון מבנים,
ביטול עם החזר משאבים, ומגבלות כמות למבנים מיוחדים.

### קרב
לכל יחידה: תקיפה, סוג תקיפה (מגע / חודר / מצור / נ״מ), שריון ושריון חודר, טווח וקצב.
מעליהם מערכת יחסי חוזק:

| התוקף | חזק מול | חלש מול |
| --- | --- | --- |
| חי״ר | פרשים, מצור | יחידות אוויריות |
| לוחמי טווח | חי״ר | פרשים |
| פרשים / שריון | לוחמי טווח, מצור, פועלים | חי״ר |
| מצור | מבנים | פרשים |
| אווירי | מצור, פועלים | נ״מ והגנה אווירית |

בנוסף לכל יחידה בונוסים משלה (נושא חנית נגד פרשים, נ״מ נגד אוויר, איל ניגוח נגד מבנים).

### מערכת הצמיחה (במקום עידנים)
כל אומה מתחילה ביישוב קטן וגדלה בארבעה שלבים. המעבר דורש **משאבים + אוכלוסייה + מבנים** ולוקח זמן.
כל שלב משנה את **המראה והשם של מרכז היישוב**, פותח מבנים, יחידות וטכנולוגיות, מוסיף לתקרת האוכלוסייה
ומגדיל את **רדיוס השליטה** על המפה (מצויר כמעגל מקווקו).

### ישראל — בחירות

**לפני המשחק בוחרים נקודת פתיחה:**

* **קיבוץ 🌻** — כלכלה שיתופית: +15% איסוף, מחקר מהיר ב-20%, חדר אוכל ומפעל,
  ובסוף המסלול **עיר תעשייה והייטק** (בונוסים למחקר, שריון וטכנולוגיה).
* **מושב 🚜** — משקים פרטיים: בתים וחוות זולים ב-15%, +3 אוכלוסייה לכל בית, +30% זהב ממסחר,
  ובסוף המסלול **עיר מסחר וחקלאות**.

**בשלב 3 (עיירה) בוחרים זרוע צבאית:** חי״ר 🎖️ · שריון 🚐 · צלפים וכוחות מיוחדים 🎯 · הגנה אווירית 📡.

**מבנים ייחודיים:** מגדל מים 💧, חדר אוכל 🍽️, בית ספר 🏫, בסיס צבאי 🏕️,
מערכת הגנה אווירית 📡, בית חולים 🏥 ובורסה 💹.

## הוספת אומה חדשה

המערכת מונעת נתונים — אין צורך לגעת בקוד המנוע:

1. מוסיפים יחידות ל-`src/data/units.json` (מזהה, שם, אמוג׳י, סוג, עלות, נתוני קרב).
2. מוסיפים מבנים ל-`src/data/buildings.json`. מבנה שמאמן יחידות מציין אותן ב-`trains`.
3. מוסיפים רשומת אומה ל-`src/data/nations.json` עם ארבעה שלבי צמיחה,
   רשימות `unlocks` לכל שלב, ואופציונלית `branches` (בחירות של השחקן).
4. `npm test` — בדיקת `tests/data.test.ts` תאמת שכל ההפניות תקינות ושיש נתיב יחידות מלא.

ה-AI מסווג מבנים לפי תפקיד ישירות מהנתונים (בית / נקודת פריקה / מבנה צבא / הגנה / מחקר / כלכלה),
ולכן הוא יודע לשחק עם אומה חדשה בלי שינוי קוד.

## יריב המחשב

ארבע רמות קושי — **קל · רגיל · קשה · אכזרי** — שנבדלות בקצב החשיבה, יעד הפועלים, מספר מבני הצבא,
גודל גלי ההתקפה, תדירותם ומידת האגרסיביות. ה-AI:

* מאזן פועלים בין ארבעת המשאבים לפי יחס מטרה ולפי מחסור בפועל;
* בונה לפי סדר עדיפויות (בתים כשהאוכלוסייה נחנקת → נקודות פריקה → דרישות השלב הבא → צבא → כלכלה → מחקר → הגנה);
* בוחר יחידות לאימון לפי הצבא שהוא רואה אצל היריב (מנצל בונוסים);
* מתקדם בשלבי הצמיחה ובוחר ענפים בעצמו;
* מגיב להתקפות על הבסיס ושולח גלי התקפה לעבר המבנה הקרוב של היריב.

## אמנות ואודיו

הגרפיקה כרגע **פרוצדורלית + אמוג׳י** כ-placeholder: הקרקע מצוירת מראש לקנבס נפרד (מהיר),
והיחידות והמבנים מצוירים כאמוג׳י עם טבעת בצבע הבעלים, צל, פס חיים ואנימציית תקיפה.

**להחלפה בספרייטים** — בלי לגעת בשאר הקוד:

```ts
import { registerSprite } from './render/sprites';
registerSprite('il_worker', { image: myAtlas, sx: 0, sy: 0, sw: 64, sh: 64 });
```

כל ציור עובר דרך `drawSprite(ctx, id, emoji, …)`, שמשתמש בספרייט אם נרשם ואחרת באמוג׳י.

האודיו נוצר בזמן אמת ב-WebAudio (בלי קבצים): בחירה, פקודה, בנייה, אימון, מכה, מוות, מעבר שלב,
התראת התקפה, ניצחון והפסד, ועוד מוזיקת רקע רגועה. להחלפה בקבצים אמיתיים ממלאים את `SOUND_FILES`.

## החלטות עיצוב שהתקבלו בדרך

נקודות שלא פורטו בבקשה והוכרעו כאן:

1. **ממשק ב-DOM מעל הקנבס** ולא טקסט מצויר בקנבס — כדי לקבל RTL אמיתי, שבירת שורות נכונה בעברית,
   נגישות וגדלי מגע נוחים במובייל. רק שדה המשחק והמיני-מפה מצוירים בקנבס.
2. **Canvas 2D ולא PixiJS** — אין תלות ריצה חיצונית, הבנייה קטנה (~47KB gzip), וזה מספיק לעומס הנוכחי.
   שכבת הקרקע נצרבת פעם אחת לקנבס נפרד כדי לא לצייר 16,384 אריחים בכל פריים.
3. **מרכז אריח ב-(x+0.5, y+0.5)** והמרה לאריח ב-`Math.floor` בכל המנוע (`toTile`).
4. **חוות מייצרות אוכל באופן פסיבי** ולא כאריח שנחרש ומתרוקן — פשוט יותר, שומר על כלכלה זורמת בשלבים המאוחרים.
5. **תיקון מבנים חינם** (ללא עלות משאבים) ובקצב של 3.5% מנקודות החיים לשנייה — כדי לא להעניש בנייה הגנתית.
6. **אין לחימה ימית ואין ספינות** — המים משמשים כמכשול טבעי, כמקור דגים ולעיצוב המפה בלבד.
7. **בניית מבנה גובה את מלוא המחיר מראש**; ביטול מחזיר את החלק שטרם נבנה.
8. **יחידות אוויריות מתעלמות מקרקע** (עפות מעל מכשולים) ונפגעות במיוחד מנ״מ ומהגנה אווירית.
9. **מעבר שלב הוא השקעה**: המשאבים נגבים בהתחלה, יש טיימר, וביטול מחזיר הכול.
10. **בחירת ענף בזמן משחק משהה את המשחק** (שלב 3 אצל ישראל ויפן והערבים) כדי שהבחירה תהיה מודעת.
11. **תקרת אוכלוסייה מוחלטת: 200** — שומרת על ביצועים יציבים גם במשחק ארוך.
12. **ה-AI לא מרמה במשאבים**; ההבדל בין הרמות הוא בקצב ההחלטות, ביעדים ובאגרסיביות בלבד.
13. **המשחק נשמר בסלוט אחד ("auto") דרך שמירה מהירה**, ורשימת השמירות במסך הפתיחה תומכת בכמה סלוטים
    למי שירצה להוסיף בעתיד.
14. **זום פתיחה מותאם למסך** — במובייל רואים בערך 20 אריחים לרוחב, כדי שהמשחק יהיה שחיק במסך קטן.

## גישה לתוכן

הסגנון קליל ולא־ריאליסטי, ובנוי סביב בנייה, כלכלה, צמיחה ואסטרטגיה.
כל האומות מוצגות בכבוד ובעומק שווה — לכל אחת מסלול צמיחה מלא בן ארבעה שלבים, יתרונות ייחודיים,
מבנים משלה ותיאור שמדגיש תרבות, מדע, מסחר או בנייה. היריבים במשחק הם אומות שנשלטות על ידי המחשב,
ואין במשחק ייצוג של סכסוכים או של קבוצות אמיתיות בהווה.
